# Local Communication

### Offline Emergency Communication System for Disaster Scenarios

An offline messaging application designed to maintain communication during disasters when traditional internet and cellular networks become unavailable.

Built to support reliable, local communication in emergency situations using an ESP-01 Wi-Fi module.

### Key Features

- Offline messaging over a local Wi-Fi network
- Real-time communication using Socket.IO
- ESP-01 (ESP8266) based wireless connectivity
- Emergency-oriented communication infrastructure
- Communication without cellular networks or internet access
